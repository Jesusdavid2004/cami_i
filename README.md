# cami_i

Aplicación Angular desplegable en Vercel.

## Vercel

En Vercel, configura **Framework Preset: Angular**, **Build Command: `npm run build`** y **Output Directory: `dist/app/browser`**. El archivo `vercel.json` aplica estos ajustes y agrega los encabezados COOP/COEP.

Si conectas el repositorio desde la carpeta principal que contiene otra carpeta `app`, selecciona esa carpeta interior como **Root Directory**.
